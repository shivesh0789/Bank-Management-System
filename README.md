# 🏦 Bank Management System

A simple **Bank Management System** developed using **C++**.  
This project allows users to create and manage bank accounts through a menu-driven console application.

## 👨‍💻 Author

**Shivesh Kumar**

## ✨ Features

- Create a new bank account
- Display all accounts
- Search an account
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Delete an account
- Update account details
- Save account data to a file

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- Arrays
- Functions
- Classes and Objects

## ▶️ How to Run
